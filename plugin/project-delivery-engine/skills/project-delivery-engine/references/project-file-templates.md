# 项目文件模板

本文件只在新建或修复项目文件时读取。模板中的占位符必须替换；未知事实写成明确待确认项。

当前项目结构版本：`2`。结构版本只用于机械迁移检查，不要求在项目中另建版本文件。

项目文件应能随整个项目目录移动，不保存会过期的固定绝对路径。项目移动后给命令传入新的 `--root`；绑定旧项目根的编译计划不得继续执行，必须在新位置重新 `propose`。

## STATUS.md

影响基线、完成判断或重要风险的验证，在现有单元格或证据引用中写清实际对象及足以区分产物的版本、指纹等信息，并按需记录时间、环境和覆盖范围。不强制新增列；未执行或受阻如实填写，不把预期结果写成已验证。具体边界见 [project-state.md](project-state.md) 的“状态与验证的对应”。

```text
# STATUS.md

## 当前状态

| 项目 | 状态 | 依据 |
| --- | --- | --- |

## 验证

| 验证项 | 结果 | 层级 |
| --- | --- | --- |

层级取值 `主线` 或 `旁证`；`旁证` 为真实但不推进主线的观察，不得进入 `TODO.md` 的下一步。

## 风险

- 

## 关键引用

- 
```

## HANDOFF.md

`HANDOFF.md` 必须且只能有一个 `## 语义检查点` 章节，并把它放在 `# HANDOFF.md` 标题后的第一个内容区块；下列两项声明必须各出现一次。时间必须是真实日历时间，格式为 `YYYY-MM-DD HH:mm 时区`；时区使用 `Z`、`UTC`、`+08:00` 这类偏移量或 `Asia/Shanghai` 这类 IANA 时区名。

`## 已证伪路线` 只记录对后续项目工作仍有复用价值、已经由证据关闭的路线或假设；普通测试失败、一次性调试尝试和临时过程不写入。已登记路线不得重测，除非该行复开条件已满足；前提变化时的核验和受控修订按 [project-state.md](project-state.md) 执行，不直接删除旧证伪记录。

```text
# HANDOFF.md

## 语义检查点

- 最后语义检查点：<YYYY-MM-DD HH:mm +08:00 或 Asia/Shanghai>
- 检查点后变化：<已核对或待确认>
```
